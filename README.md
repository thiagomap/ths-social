# THS Social

Mídia pública dos carrosséis da **THS Gestão em Saúde** — https://www.thsgestaoemsaude.com

Este repositório existe por um motivo técnico: a Graph API da Meta só publica imagens a
partir de URL pública acessível, e o repositório do site é privado. Aqui ficam apenas as
artes já destinadas a virar post — nenhum código-fonte.

Os arquivos são servidos por `raw.githubusercontent.com`, e as URLs entram no
`publicar-direto.mjs` na hora de publicar.

| Carrossel | Slides |
|---|---|
| `calculos-*` | Cálculos Técnicos e Faturamento SUS |
| `consultoria-*` | Consultoria e Assessoria em Gestão |
| `formacao-*` | Cursos e Mentoria Online |
| `ia-*` | Ferramentas e Painéis com IA |

Formato: JPEG 1080×1350 (4:5), dentro dos limites de publicação do Instagram.
